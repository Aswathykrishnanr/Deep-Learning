# Deep Learning Practice

This repository contains a collection of projects and experiments I built while learning **Deep Learning and Computer Vision**. The goal is to understand how different AI techniques work and apply them to practical problems.

While learning these topics, I experimented with several concepts such as neural networks, object detection, face recognition, OCR, and speech recognition.

---

## Repository Contents

* **ANN** – Experiments with Artificial Neural Networks
* **Computer Vision** – Image processing and computer vision basics using OpenCV
* **Face Detection** – Detecting faces in images and webcam streams
* **Face Recognition** – Recognizing and identifying people using facial features
* **OCR** – Extracting text from images using Optical Character Recognition
* **Speech Recognition** – Converting spoken language into text
* **MediaPipe** – Experiments with MediaPipe for real-time face and hand tracking
* **YOLO** – Object detection experiments using YOLO models

---

## Technologies Used

* Python
* OpenCV
* NumPy
* MediaPipe
* Deep Learning frameworks and models
* YOLO for object detection
