# Artificial Neural Networks (ANN)

This folder contains experiments and implementations related to Artificial Neural Networks.

## Description

Artificial Neural Networks are one of the fundamental models used in deep learning. These experiments focus on understanding how neural networks work, including concepts like forward propagation, activation functions, and training.

## Technologies Used

* Python
* NumPy
* Basic deep learning concepts

## Features

* Simple neural network implementations
* Experiments with network behavior
* Understanding how neural networks learn from data
