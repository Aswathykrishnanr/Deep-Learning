# YOLO Object Detection

This project explores object detection using the YOLO (You Only Look Once) model.

## Description

YOLO is a deep learning model used for real-time object detection. This project demonstrates detecting multiple objects from images or live video.

## Technologies Used

* Python
* OpenCV
* YOLO model

## Features

* Detect multiple objects in images
* Real-time object detection using webcam
* Bounding boxes with object labels
