# Face Detection

This project demonstrates how to detect human faces in images or video streams using computer vision techniques.

## Description

The system identifies faces in real-time using a webcam or from image inputs. It draws bounding boxes around detected faces.

## Technologies Used

* Python
* OpenCV
* Computer Vision techniques

## Features

* Detect faces from images
* Real-time face detection using webcam
* Highlight detected faces with bounding boxes
