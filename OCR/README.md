# Optical Character Recognition (OCR)

This project extracts text from images using OCR techniques.

## Description

OCR allows machines to read printed or handwritten text from images. This project demonstrates extracting text using OCR tools.

## Technologies Used

* Python
* OpenCV
* OCR libraries

## Features

* Extract text from images
* Preprocess images for better recognition
* Display extracted text in the console
