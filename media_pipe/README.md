# MediaPipe Experiments

This folder contains experiments using MediaPipe for real-time machine learning pipelines.

## Description

MediaPipe provides tools for building real-time applications involving face detection, hand tracking, and body pose estimation. These experiments explore some of those capabilities.

## Technologies Used

* Python
* MediaPipe
* OpenCV

## Features

* Face tracking
* Hand tracking
* Real-time processing from webcam

## Output

Example results from MediaPipe experiments are available in this folder.
